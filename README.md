# 📚 Library Management System

## About the Project

The Library Management System is a simple web-based project developed using HTML, CSS, and JavaScript. It helps users manage library books easily.

## 🚀 Features

* 🔐 Login Page
* 📚 Add Books
* 📖 View All Books
* 🔍 Search Books
* 📤 Issue Books
* 📥 Return Books
* 🎨 Simple and User-Friendly Interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* LocalStorage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Start using the Library Management System.

## 💾 Data Storage

This project uses browser LocalStorage to store book information.
